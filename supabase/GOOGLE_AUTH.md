# تفعيل الدخول بحساب Google

التطبيق جاهز: الزرّ موجود، والتدفّق مكتوب، والرابط العميق مسجَّل في
المانيفست. تبقى خطوتان خارج الكود.

**قبل تنفيذهما لا يتعطّل شيء:** الزرّ يبقى مخفياً تلقائياً حتى تكتمل
التهيئة، والدخول بالاسم المستعار يعمل كما هو.

> **لا تحتاج بصمة SHA-1 ولا عميل Android.** التدفّق يمرّ عبر متصفّح
> Chrome المدمج (Custom Tab) ثم يعود إلى التطبيق بالرابط العميق، فيكفي
> عميل **Web application** واحد.

---

## الخطوة 1 — Google Cloud Console

افتح [console.cloud.google.com](https://console.cloud.google.com).

1. أنشئ مشروعاً جديداً (أو اختر مشروع Firebase الحالي الخاص باللعبة).
2. **APIs & Services → OAuth consent screen**:
   - نوع المستخدم: **External** → Create
   - اسم التطبيق: `Ronda Tahiro` · بريد الدعم: بريدك
   - Developer contact: بريدك → Save and Continue حتى النهاية
   - أثناء التطوير ضع بريدك في **Test users**، وعند الجاهزية اضغط
     **Publish app** ليتمكّن كل اللاعبين من الدخول.
3. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - Application type: **Web application**
   - Name: `Ronda Supabase`
   - تحت **Authorized redirect URIs** اضغط ADD URI والصق بالضبط:

```
https://hovdirfdolcdtvnblpfq.supabase.co/auth/v1/callback
```

4. اضغط Create، واحتفظ بـ **Client ID** و**Client secret**.

---

## الخطوة 2 — Supabase

افتح مشروعك في [supabase.com](https://supabase.com).

**أ) فعّل المزوّد:** Authentication → **Providers** → Google →
فعّل **Enable Sign in with Google** → الصق الـ Client ID والـ Client
secret → **Save**.

**ب) اسمح بالرابط العميق:** Authentication → **URL Configuration** →
تحت **Redirect URLs** اضغط Add URL والصق بالضبط:

```
com.rondatahiro.myapp://login-callback
```

ثم Save. **هذه الخطوة هي الأكثر نسياناً** — بدونها يرفض Supabase العودة
إلى التطبيق وتبقى صفحة المتصفّح مفتوحة.

---

## الخطوة 3 — التجربة

1. انشر التطبيق وثبّته.
2. في شاشة الدخول سيظهر زرّ **المتابعة بحساب Google** فوق حقل الاسم.
3. اضغطه → يُفتح متصفّح داخل التطبيق → اختر حسابك.
4. يُغلق المتصفّح وحده، ويظهر ترحيب باسمك من Google، وتدخل اللوبي.
5. أعد فتح التطبيق: يظهر مكان الزرّ شريط أخضر «حسابك مرتبط بـ Google»،
   وحقل الاسم مُعبّأ باسمك — يكفي ضغط «ابدأ اللعب».

---

## ماذا يكسب اللاعب

معرّفه في اللعبة يصير مشتقّاً من حسابه في Google، فيكون **واحداً على كل
جهاز**. فإذا غيّر الهاتف أو أعاد التثبيت ودخل بالحساب نفسه، عاد ترتيبه
وسجلّه كما كانا.

وعند أول ربط يُنقل سجلّه المحلي من المعرّف العشوائي القديم إلى الجديد
تلقائياً، فلا يفقد تاريخه على هذا الجهاز.

> **ما لا ينتقل بين الأجهزة:** الذهب والصناديق والإنجازات — فهي محفوظة
> في ذاكرة الهاتف لا في الخادم. نقلها يحتاج حفظها في Supabase أيضاً،
> وهو عمل منفصل.

## إلغاء الربط

زرّ «إلغاء الربط بـ Google» ينهي الجلسة ويمسح بيانات الحساب، لكنه
**لا يُعيد المعرّف القديم** — لأن إعادته تيتّم الإحصائيات المسجَّلة تحت
المعرّف الجديد. فاللاعب يحتفظ بتقدّمه ويفقد المزامنة بين الأجهزة فقط.

## إن لم ينجح

| ما تراه | السبب الأرجح |
|---|---|
| الزرّ لا يظهر أصلاً | مكتبة Supabase لم تُحمَّل — تحقّق من الإنترنت |
| «Error 400: redirect_uri_mismatch» | رابط الخطوة 1 غير مطابق حرفاً بحرف |
| المتصفّح يفتح ولا يعود للتطبيق | الخطوة 2-ب لم تُنفَّذ |
| «Access blocked: app not verified» | شاشة الموافقة ما زالت Testing — أضف بريدك في Test users أو اضغط Publish app |

ولتشخيص أدقّ: Supabase → Authentication → **Logs**.
